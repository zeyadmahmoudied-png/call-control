# التحكم في المكالمات (Call Control)

تطبيق أندرويد يعمل دون إنترنت للتحكم في المكالمات الواردة حسب قواعد: لكل رقم، لغير المسجل، للمخفي، والوضع العام (مع جدولة).

الحالات: **متاح** (سماح) · **مشغول** (رفض) · **غير متاح** (رفض، نفس إجراء مشغول) · **صامت** (كتم الرنين).
الأولوية: قاعدة الرقم ← غير المسجل ← المخفي ← الوضع العام (الجدولة تحدد الوضع العام فقط). أي خطأ داخلي = سماح بالمكالمة.

## التثبيت والتفعيل
1. ثبّت الـ APK من صفحة Releases (Android 10 أو أحدث).
2. افتح التطبيق واضغط «تفعيل» ليظهر حوار النظام الرسمي، واختر التطبيق كتطبيق فرز المكالمات.
   يدويًا: الإعدادات ← التطبيقات ← التطبيقات الافتراضية ← تطبيق معرّف المتصل والبريد المزعج.

## الأذونات
- `READ_CONTACTS` اختياري، لمعرفة هل الرقم محفوظ. بدونه لا تُطبَّق قاعدة «غير المسجل» أبدًا.
- لا إنترنت، لا سجل مكالمات النظام. كل البيانات على الهاتف.

## حدود لا يتحكم فيها التطبيق
«مشغول» و«غير متاح» يرفضان من الهاتف بنفس الطريقة. ما يسمعه المتصل (مشغول/بريد/رسالة) تحدده شبكة المشغّل، ولا يمكن للتطبيق جعلها تعلن أن الهاتف مغلق. سلوك e& الفعلي لم يُختبر.

## البناء والاختبار
`./gradlew :domain:test :storage-core:test` ثم `./gradlew :app:assembleDebug`. اختبارات الجهاز والمحاكي تعمل في GitHub Actions (`ci.yml`)، والإصدار الموقّع من `release.yml`.
